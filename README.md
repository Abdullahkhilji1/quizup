# 🎯 QuizUp - Console-Based Quiz Application in C

QuizUp is an interactive command-line application built using the C programming language. It allows users to test their knowledge across multiple subjects including Computer Science, Mathematics, Physics, and General Science.

## 🚀 Features
- **Multi-Subject Selection:** Choose from 4 different domains (CS, Math, Physics, General Science).
- **Interactive Scoring System:** Tracks correct answers dynamically and produces a final score out of 10.
- **Instant Performance Feedback:** Provides custom feedback messages based on overall score performance.

## 🛠️ Built With
- **Language:** C
