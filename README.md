# QuizUp – C Programming Quiz Application

## 📌 Project Overview

**QuizUp** is a console-based quiz application developed in **C Programming**. It allows users to select a quiz category and answer multiple-choice questions. At the end, the application calculates the user's score and displays performance feedback.

## 🎯 Quiz Categories

* 💻 Computer Science
* ➗ Mathematics
* ⚛️ Physics
* 🔬 General Science

## ✨ Features

* Category-based quiz selection
* Multiple-choice questions (MCQs)
* User input handling
* Automatic score calculation
* Final score display
* Performance-based feedback
* Simple console-based interface

## 🛠️ Technologies Used

* **C Programming**
* Standard Input/Output
* Conditional Statements
* Variables
* `if-else`
* `scanf()` and `printf()`

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Abdullahkhilji1/QuizUp.git
```

### 2. Open the project

Open the project folder in **VS Code**, Code::Blocks, Dev-C++, or another C compiler.

### 3. Compile the program

```bash
gcc quizup.c -o quizup
```

### 4. Run the program

Windows:

```bash
quizup.exe
```

Linux/macOS:

```bash
./quizup
```
